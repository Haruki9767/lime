# Visual Reference — the "premium hero" pattern

This skill is modeled on four reference layouts (travel/destination and product-launch landing pages). They all share one structural DNA. Use this as a checklist when building any hero.

## Shared structure across all four references

| Element | Detail |
|---|---|
| Frame | Whole hero sits inside a large rounded-rect card (not full browser-edge-to-edge on the outer page — there's a visible page background behind/around the card in some variants, full-bleed in others) |
| Background | One full-bleed photo (cityscape at night, dense forest, aerial coastline, cinematic film-set matte painting) — always a single image, never split/collaged, never a gradient |
| Overlay | Flat dark scrim (solid black at low opacity) over the image so white text stays legible — strongest at the bottom-left where text sits, can fade to lighter at top-right nav |
| Logo/brand mark | Small, top-left, sometimes a pill-shaped badge (Tokyo example), sometimes a simple wordmark + icon (Forest, Star Wars) |
| Nav | Thin, uppercase-or-title-case text links, top-right, generously spaced, small font (12–14px). Optional search icon or CTA pill button at the far right |
| Headline | The dominant visual element. Extremely bold weight, large size, tight letter-spacing, 1–2 words or a short phrase, positioned lower-left-third. Pure white or near-white |
| Subhead | One short line directly below headline, lighter weight, smaller, often includes a stylized ellipsis or tagline ("...not so far away") |
| Caption/eyebrow block | Bottom-left corner: small label (e.g. "Culture Festival"), a date or detail line under it, separated from a short description by a thin vertical divider line |
| Secondary nav/social | Bottom-left or bottom-right: social icons row, OR pagination dots/slide indicators on the right edge |
| CTA buttons (when present) | Solid fill or solid outline, rectangular or slightly rounded, no gradient fill, high contrast against the photo |

## Per-reference notes

**Tokyo (image 1)**: pill-shaped logo badge top-left; nav top-right with search icon; vertical pagination dots on the right edge; bottom-left eyebrow block (event name + date) with a description line separated by a vertical rule; social icons bottom-right.

**Forest (image 2)**: simple hamburger + wordmark top-left; minimal 2-link nav + search icon top-right; giant lowercase headline with a decorative underline accent; badge row bottom-right (govt/certification badges as small circular icons + label) instead of social icons — shows the pattern is flexible for "trust badges" too.

**Into the Wild (image 3)**: text-only nav both sides (no logo mark, just "Home" left / utility links right — Download app, Search, Sign in, Register); two-line headline; body paragraph (3 lines) under the subhead — more copy than the others; two solid CTA buttons side by side ("Explore all trips" / "Explore packages") with one solid-fill and one solid-outline treatment; social icons + slide dots both bottom-left, stacked.

**Star Wars (image 4)**: brand logo top-left; full text nav top-right ending in a solid-fill pill CTA button ("Find prices"); search input embedded directly in the hero body under the headline (search icon + placeholder text + underline rule) rather than only in the nav; small inset video-thumbnail-with-play-button floating mid-right — this is the "video variant" cue: a supplementary video preview can float as a secondary element even when the main background is a still image; bottom-left shows a mini itinerary/breadcrumb ("01 Planet Batuu — Millennium Falcon") in place of the event caption; carousel arrows bottom-right.

## Takeaways for building new heroes

- Always: full-bleed single image or video, dark solid scrim, bold lower-left headline, thin top-right nav.
- Rotate based on content need: eyebrow caption block (editorial/event sites), trust badges (credibility-driven sites), body paragraph + dual CTAs (conversion-driven sites), embedded search bar (utility/booking sites), mini video preview inset (media-rich sites).
- Keep exactly one accent treatment per site — don't combine pill badge + solid CTA + trust badges all at once unless the content genuinely needs all three; the reference set achieves richness through restraint, not density.
